# 5t5：无限

咒术回战同人顶视角割草。走位，叠术式，把涌上来的秽物割平。

> 同人作品，与官方无关。

## 玩法

- 选人：**5t5**（无极）或 **宿傩**（斩击）
- **WASD** / 左摇杆走位
- 术式自动释放；升级三选一往身上叠
- **Shift / F / 右侧按钮**：位移（5t5 瞬移，宿傩 瞬斩）
- 解锁 **虚式** 后按 **E** 主动放
- 解锁 **术域** 后按 **空格**
- **黑闪** 会连锁弹跳，击杀喷血

## 本地运行

需要 Node.js 22+。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:8080](http://localhost:8080)。

```bash
npm run build
```
